📲 앱으로 설치하기

이 주소를 공유하면 누구나 쓸 수 있고, 기기에 설치해 일반 앱처럼 쓸 수 있습니다:

  • 안드로이드 (Chrome): ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
  • 아이폰 (Safari): 하단 공유 버튼 → "홈 화면에 추가"
  • PC (Chrome/Edge): 주소창 오른쪽 설치 아이콘 클릭

설치하면 오프라인에서도 열리며, 입력한 데이터는 각자 기기에 따로 저장됩니다.

📐 종합점수 산정 기준 (100점)

  • 20~40대 비율 15점 — 25%에서 0점, 50%에서 만점
  • 가격 갭 15점 — 신축 평당가 대비 재건축 평당가가 쌀수록 높음 (안전마진)
  • 역 이용객 10점 · 상권 점포 10점 · 신축 평당가 10점
  • 전세가율 10점 — 50%에서 0점, 80%에서 만점 (실수요·갭투자 용이)
  • 공급 부담 10점 — 입주 예정 0세대 만점, 5,000세대 이상 0점
  • 용적률 여유 10점 — 평균 150% 이하 만점, 250% 이상 0점
  • 인구 규모 5점 · 추진 단계 5점

미입력 항목은 0점 처리되며 막대가 회색으로 표시됩니다.

📊 항목별 자료 얻는 곳

  • 인구/연령: jumin.mois.go.kr → 연령별 인구현황 → 행정동 선택 후 조회
  • 역 승하차: 공공데이터포털에서 "지하철 승하차" 검색 (서울은 열린데이터광장, 코레일 구간은 철도통계)
  • 상권 점포 수: 소상공인시장진흥공단 상가(상권)정보 — 공공데이터포털 API 또는 각 지자체 데이터포털
  • 실거래 최고가/전세: 국토부 실거래가 공개시스템, 네이버부동산
  • 입주 예정: 청약홈 · 부동산지인 · 아실(asil) 입주물량 메뉴
  • 용적률: 네이버부동산 단지정보 또는 K-apt(공동주택관리정보시스템)
  • 추진 단계: 각 시·군·구청 고시공고, 정비사업 통합홈페이지(서울은 cleanup.seoul.go.kr)

🤖 자동 갱신 파이프라인

실거래 최고가·평당가 · 전세가율 · 상권 점포 수는 매월 자동으로 갱신됩니다:

  1. data.go.kr 무료 가입 → 3개 API 활용신청 (아파트 매매 실거래가 상세 / 아파트 전월세 실거래가 / 소상공인 상가(상권)정보)
  2. GitHub 리포지토리 Settings → Secrets → Actions에 DATA_GO_KR_KEY 등록
  3. 분석할 동네를 dongne/targets.json에 추가 (동 이름, 시군구코드, 단지명)

이후 매월 GitHub Actions가 dongne/output/auto.json을 갱신하고, 웹으로 배포된 앱은 접속할 때 자동으로 반영합니다 (Actions 탭에서 수동 실행도 가능). 수동으로 입력한 값은 보존되고 자동 조회 항목만 덮어씁니다.
