# 🏘️ 재건축 동네분석

엑셀로 수작업하던 행정동 단위 재건축 분석을 **폰/PC 브라우저에서 바로 쓰는 앱**으로 옮긴 것.
서버·DB·로그인 없이 HTML 파일 하나로 동작한다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (입력 + 자동계산 + 점수 + 비교표). 이 파일 하나면 끝 |
| `fetch_data.py` | 2단계 자동화 — 공공데이터포털 API로 실거래가·전세가율·점포수 자동 조회 |
| `manifest.webmanifest` | 폰 홈 화면에 "앱처럼" 추가할 때 쓰는 설정 |

## 기능

- 엑셀 항목 그대로: 인구/20~40대, 역 승하차, 상권 점포수, 신축·해당동·재건축 최고가,
  전세가율, 향후 입주, 용적률, 추진단계
- **자동 계산**: 20~40대 비율, 전세가율, 가격 갭(신축 vs 재건축 평당가)
- **종합점수(100점) + 등급(S~D)**: 산정 기준은 앱의 [가이드] 탭 참고
- **동네 비교표**: 등록한 동네를 항목별로 나란히 비교, 최고값 하이라이트
- 데이터는 브라우저에 저장(localStorage), **JSON 내보내기/가져오기**로 폰↔PC 이동
- 다크모드, 모바일 우선 반응형, 본오동 예시 데이터 내장

## 사용법

가장 간단한 방법 두 가지:

1. **파일로 열기** — `index.html`을 더블클릭 (PC), 폰에는 파일을 보내서 브라우저로 열기
2. **웹으로 배포** — Vercel/Netlify/GitHub Pages에 `dongne/` 폴더를 올리면 URL 하나로
   폰·PC 어디서든 접속. 폰 브라우저에서 "홈 화면에 추가"하면 앱 아이콘처럼 쓸 수 있다

> 데이터는 **기기(브라우저)별로 따로 저장**된다. 폰과 PC에서 같이 쓰려면
> [가이드] 탭의 내보내기 → 파일 전송 → 가져오기를 이용.

## 2단계: 자동화 (`fetch_data.py`)

공공데이터포털 인증키 **하나**로 실거래 최고가 / 전세가율 / 상권 점포수를 자동 조회한다.

1. [data.go.kr](https://www.data.go.kr) 무료 가입 후 아래 3개 API 활용신청 (자동 승인)
   - 국토교통부_아파트 매매 실거래가 상세 자료
   - 국토교통부_아파트 전월세 실거래가 자료
   - 소상공인시장진흥공단_상가(상권)정보
2. `.env`에 `DATA_GO_KR_KEY=발급키` 추가
3. 실행 (예: 본오동):

```bash
python dongne/fetch_data.py --name 본오동 --lawd 41271 --umd 본오동 \
    --adong 4127160000,4127161000,4127162000 --months 6
```

- `--lawd` 법정동코드 앞 5자리: [code.go.kr](https://www.code.go.kr)에서 검색
- `--adong` 행정동코드 10자리 (본오1·2·3동처럼 여러 개면 쉼표 구분)
- 결과: `dongne/output/<동이름>.json` → 앱 [가이드 → 가져오기]로 불러오면 자동 반영
- 단지별 최고가 목록도 터미널에 출력되므로 신축/재건축 단지 가격은 목록에서 골라 입력

### 자동화 커버리지

| 항목 | 자동화 | 방법 |
|---|---|---|
| 실거래 최고가·평당가 | ✅ | fetch_data.py (국토부 실거래가 API) |
| 전세가율 | ✅ | fetch_data.py (전월세 API, 순수 전세만 집계) |
| 상권 점포수 | ✅ | fetch_data.py (소상공인 상가정보 API) |
| 인구/20~40대 | 반자동 | [jumin.mois.go.kr](https://jumin.mois.go.kr) 조회 후 입력 (KOSIS API로 확장 가능) |
| 역 승하차 | 반자동 | 공공데이터포털 "지하철 승하차" 검색 (운영사별 API 상이) |
| 입주 예정 | 수동 | 아실·부동산지인 입주물량 |
| 용적률 | 수동 | 네이버부동산 단지정보 / K-apt |
| 추진단계 | 수동 | 시·군·구청 고시공고 |
