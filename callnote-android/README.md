# 📱 매통이 안드로이드 앱

웹 매통이(`../callnote/`)를 감싸는 네이티브 안드로이드 앱.
웹 버전과 달리 **통화가 끝나면 자동으로 녹음 파일을 찾아 알림을 띄운다** — 공유 버튼을 누를 필요가 없다.

```
통화 종료 (PHONE_STATE 감지)
    ↓ 6초 뒤 (녹음 파일 저장 대기, 최대 2회 재시도)
미디어저장소에서 방금 저장된 통화 녹음 탐색 (경로/파일명에 call·통화 포함)
    ↓
🔔 알림: "통화 녹음이 저장됐어요 — 탭하면 AI 정리 여부를 선택"
    ↓ 탭
앱(WebView)이 열리고 녹음이 자동 로드 → "정리할까요?" 팝업 → [지금 AI로 정리]
```

화면 자체는 배포된 웹앱(https://land3lab.github.io/mrhomesga/callnote/)을 WebView로 띄우므로,
웹을 고치면 앱도 다음 실행부터 자동 반영된다 (앱 재설치 불필요).

## 구성

| 파일 | 역할 |
|---|---|
| `app/src/main/java/.../MainActivity.kt` | WebView + 권한 요청 + 녹음 파일을 웹으로 주입(JS 브릿지) + 공유 수신 |
| `.../CallReceiver.kt` | 전화 상태 브로드캐스트 수신 — 통화 종료 감지 |
| `.../MonitorService.kt` | "매통이 실행 중" 지속 알림(포그라운드 서비스) — 실행 상태 표시 + 프로세스 유지 |
| `.../BootReceiver.kt` | 기기 부팅 완료 시 감지 서비스 자동 시작 (BOOT_COMPLETED) |
| `.../RecordingCheckWorker.kt` | 통화 종료 6초 뒤 미디어저장소에서 새 통화 녹음 탐색 |
| `.../NotifyHelper.kt` | "정리할까요?" 알림 생성 |
| `release-key.jks` | APK 서명 키 (아래 보안 주의 참고) |
| `../.github/workflows/android-build.yml` | push 시 APK 자동 빌드 → 릴리스 게시 |

## 설치 (개발 환경 불필요)

1. GitHub **[Releases → callnote-android](../../../releases/tag/callnote-android)** 에서 `callnote.apk` 다운로드
   (기본 브랜치에 push될 때마다 CI가 자동 갱신)
2. 폰에서 파일 열기 → "출처를 알 수 없는 앱 설치" 허용 → 설치
3. 첫 실행 시 권한 4개 허용: **전화**(통화 종료 감지), **통화기록**(상대 번호 자동 입력),
   **알림**, **음악·오디오**(녹음 파일 읽기)
4. 앱 안 ⚙️ 설정 탭에서 Gemini API 키 입력 — WebView는 Chrome과 저장소가 분리되어 있어
   웹에서 입력했던 키도 앱에서 한 번 더 입력해야 한다
5. 갤럭시 전화 앱 → 설정 → 통화 녹음 → **자동 녹음** 켜기

같은 키로 서명된 APK라서 이후 새 버전 APK를 그냥 덮어 설치하면 업데이트된다 (기록 유지).

## 동작 조건 / 한계

- **통화 녹음 자체는 삼성 전화 앱이 한다.** 이 앱은 저장된 파일을 찾아줄 뿐이므로
  자동 녹음이 꺼져 있으면 알림이 뜨지 않는다.
- 통화 녹음 파일이 표준 위치(미디어저장소, 경로/이름에 call 또는 통화 포함)에 저장되는
  기종에서 동작한다 — 삼성 갤럭시 기준으로 만들었다.
- 앱을 "강제 종료"하면 다음 실행 전까지 통화 감지가 멈춘다 (안드로이드 정책).
  배터리 설정에서 매통이를 "절전 제외(제한 없음)"로 두는 것을 권장.
- 상담 기록은 WebView의 localStorage에 저장된다. 웹(Chrome)에서 쓰던 기록과는
  분리되므로, 옮기려면 웹에서 [내보내기] → 앱에서 [가져오기].

## 서명 키 보안 주의

`release-key.jks`는 **개인 사이드로드 편의용**으로 저장소에 포함했다 (비밀번호도 빌드 스크립트에 평문).
공개 저장소이므로 누구나 같은 키로 APK를 서명할 수 있다 — 즉 **이 서명을 신뢰의 근거로 쓰면 안 되며**,
APK는 반드시 본인 저장소의 Releases에서만 받아야 한다. 플레이스토어 배포 등으로 확장할 때는
새 키를 만들어 GitHub Secrets로 옮길 것.

## 직접 빌드하려면

Android Studio에서 `callnote-android/`를 열거나:

```bash
cd callnote-android && gradle :app:assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```
