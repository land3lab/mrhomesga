# 📞 통화노트 — 매물 접수 · 고객 상담 자동정리

전화 상담이 끝나면 **통화 녹음(또는 받아쓰기)을 AI가 매물 접수·고객 상담 카드로 자동 정리**해주는 앱.
dongne와 같은 방식 — 서버·DB·로그인 없이 HTML 파일 하나로 동작하는 PWA다.

```
통화 종료
  ↓  ① 갤럭시: 녹음 파일 "공유 → 통화노트"   ② 스피커폰: 실시간 받아쓰기   ③ 아이폰: 전사 텍스트 붙여넣기
Gemini AI (전사 + 구조화, JSON 강제)
  ↓
상담 카드 자동 완성 — 구분(매물접수/손님문의/계약진행) · 이름 · 연락처 · 물건 · 가격 · 면적 ·
입주일 · 특이사항 · 할 일(follow-up) · 한 줄 요약
  ↓
검토·수정 → 저장 (localStorage) → 목록에서 검색/필터, 전화걸기, 카톡용 복사, JSON 백업
```

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (입력 + AI 정리 + 목록/검색 + 백업). 이 파일 하나면 끝 |
| `manifest.webmanifest` | PWA 설치 + **share_target** (안드로이드 공유 시트에 "통화노트" 표시) |
| `sw.js` | 서비스 워커 — 오프라인 캐싱 + 공유받은 녹음 파일 수신 처리 |
| `icons/` | 앱 아이콘 |

## 왜 "전화가 오면 자동으로"가 아니라 "통화 후 공유"인가

- **iOS**는 서드파티 앱의 통화 녹음 자체를 허용하지 않는다 (iOS 18의 자체 녹음+전사 기능만 존재).
- **Android**도 웹앱/일반 앱이 통화 음성을 직접 가로채는 API를 제공하지 않는다.
- 대신 한국 갤럭시 폰은 **전화 앱 자체에 통화 자동 녹음** 기능이 있으므로,
  "통화 끝 → 녹음 파일을 공유 시트에서 통화노트로 전송 → AI 정리"가 실질적으로 가장 자동에 가까운 흐름이다.
  (앱을 홈 화면에 설치하면 공유 대상 목록에 나타난다)

## 설정 (한 번만)

1. 배포된 URL 접속 (아래 "배포" 참고) → Chrome ⋮ → **앱 설치** (홈 화면 추가)
2. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 API 키 발급
   → 앱의 **⚙️ 설정·가이드** 탭에 붙여넣고 저장
3. 갤럭시: 전화 앱 → 설정 → **통화 녹음 → 자동 녹음** 켜기

## 사용 흐름 (갤럭시 기준)

1. 통화 종료
2. 전화 앱 최근기록(또는 내 파일 → Recordings → Call)에서 녹음 → **공유 → 통화노트**
3. 앱이 열리면 **"정리할까요?" 팝업** → [🤖 지금 AI로 정리] 선택 시 받아쓰기 + 상담 카드 자동 완성
   ([나중에 직접]을 누르면 파일만 올려둔 상태로 대기)
4. 틀린 부분 수정 → **[💾 저장]**
5. 목록에서 검색·필터, 이름 옆 번호 터치로 바로 전화, [📋 복사]로 카톡/문자 공유

## 데이터·개인정보

- 상담 기록·API 키는 **기기 브라우저(localStorage)에만** 저장된다. 서버 없음.
- [🤖 AI 자동 정리]를 누를 때만 해당 통화 내용/녹음이 Google Gemini API로 전송된다.
- 백업/기기 이동은 ⚙️ 탭의 **내보내기/가져오기(JSON)** 사용.
- 본인이 참여한 통화의 녹음은 통신비밀보호법상 처벌 대상이 아니지만, 고객에게
  통화 내용이 기록될 수 있음을 안내하는 것을 권장한다.

## 배포

`.github/workflows/dongne-pages.yml`이 GitHub Pages 배포 시 `callnote/`도 함께 올린다.
배포 후 접속 주소: `https://land3lab.github.io/mrhomesga/callnote/`

> share_target(공유 수신)과 마이크 받아쓰기는 HTTPS + PWA 설치 환경에서만 동작하므로
> 파일로 직접 여는 것보다 배포된 URL로 쓰는 것을 권장.

## 구글시트 자동 정리 (공유 접수장)

기록을 저장·수정·삭제할 때마다 구글 스프레드시트에 자동 반영할 수 있다 (서버 불필요 —
사용자가 자기 구글 계정에 Apps Script 웹훅을 하나 배포하는 방식). 설정 방법과 붙여넣을
코드는 앱의 **⚙️ 설정·가이드 → 📊 구글시트 자동 정리** 안에 있다.

- 여러 직원이 **같은 웹 앱 URL**을 각자 설정에 넣으면 모든 상담이 한 시트에 모인다 (사무실 공용 접수장)
- 시트의 1행(제목)과 id 열은 갱신 기준이므로 지우면 안 됨
- 기존 기록은 [📤 기존 기록 전체 보내기]로 일괄 전송

## 발신번호 자동 입력

안드로이드 앱(callnote-android)으로 쓰면 통화기록에서 상대방 번호·저장된 이름을 읽어
연락처/이름 칸에 자동 입력하고, AI에게도 참고정보로 전달한다. 통화 중 다른 번호가
언급되면 AI가 쉼표로 구분해 함께 기록한다 (예: `010-1111-2222, 010-3333-4444(남편)`).

## 한계 / 다음 단계 아이디어

- 실시간 받아쓰기(Web Speech API)는 Chrome 계열에서만 안정적이고, 스피커폰 상대방 음성은
  마이크 품질에 따라 인식률이 떨어질 수 있다 → 중요한 통화는 녹음 파일 방식 권장
- 녹음 파일은 요청당 20MB(약 20~40분 통화)까지 — 그 이상은 나눠서 업로드
- 추후 확장: Firebase 연동으로 기기 간 자동 동기화, 매물 카드 → 네이버부동산 등록 양식 변환,
  할 일(follow-up) 알림, 다중 직원 공유
