🤖 AI 설정 (Google Gemini)

녹음 파일 전사와 자동 정리에 Google Gemini API를 사용합니다 (무료 등급으로 충분). aistudio.google.com/apikey에서 구글 계정으로 로그인 → [API 키 만들기] → 아래에 붙여넣기.

키는 이 기기 브라우저(localStorage)에만 저장됩니다. [AI 자동 정리]를 누를 때만 통화 내용/녹음이 Google Gemini API로 전송되고, 그 외에는 모든 데이터가 기기 안에만 있습니다.

📊 내 매물장 시트 (개인용)

내 기록은 내 것 — 기록을 저장·수정·삭제할 때마다 내 구글 드라이브의 스프레드시트에 자동 백업됩니다. 이 시트는 동료가 매물을 보내주는 수신함 역할도 해서, 동료가 공유한 매물이 앱을 열 때 자동으로 내 매물장에 들어옵니다. 아래 "시트 연결하는 법"을 따라 한 번만 설정하세요.

동료에게 매물을 받으려면 이 URL을 동료에게 알려줘서 동료의 [👥 공유 대상]에 등록하게 하세요. (URL을 아는 사람만 보낼 수 있습니다)

🔧 시트 연결하는 법 (한 번만, 5분)

⚠️ PC 브라우저에서 하는 것을 권장합니다. 폰의 구글시트 앱에는 스크립트 메뉴가 없어요. (폰밖에 없다면 Chrome 주소창 ⋮ → "데스크톱 사이트" 체크 후 진행 가능)

  1. 브라우저에서 script.google.com/create 접속 (구글 로그인) — 시트를 미리 만들 필요 없습니다, 나중에 자동 생성돼요
  2. 편집기 가운데 있는 기존 코드(function myFunction()…)를 모두 지우고, 아래 [📋 코드 복사]를 눌러 붙여넣기
  3. 위쪽 💾(프로젝트 저장) 클릭 — 프로젝트 이름은 아무거나 (예: 통화노트)
  4. 우상단 파란 배포 → 새 배포 → 왼쪽 ⚙️(유형 선택) → 웹 앱 → "액세스 권한이 있는 사용자"를 모든 사용자로 바꾸고 → 배포
  5. "액세스 승인" 버튼 → 내 구글 계정 선택 → "확인되지 않은 앱" 경고가 나오면 고급 → (프로젝트명)(으)로 이동 → 허용 (방금 본인이 만든 코드라 안전합니다)
  6. 생성된 웹 앱 URL(https://script.google.com/…/exec) 복사 → 위 칸에 붙여넣고 [저장] — 저장하는 순간 기존 기록까지 전부 자동 전송되고, 구글 드라이브에 "통화노트 매물 접수장" 시트가 자동으로 생깁니다
  7. [🔍 연결 테스트]를 눌러 확인 — "✅ 연결 성공"과 함께 시트를 여는 링크가 나오면 완료. 실패 메시지가 나오면 그 안내대로 고치면 됩니다

이후에는 아무것도 누를 필요 없습니다 — 기록을 저장·수정·삭제할 때마다 자동 반영되고, 인터넷이 끊긴 상태에서 저장한 기록도 다음에 앱을 열거나 인터넷이 연결되면 자동으로 올라갑니다. [📤 전체 다시 보내기]는 시트를 실수로 지웠을 때 복구용입니다.

※ 이미 쓰던 스프레드시트에 붙이고 싶다면: 그 시트를 PC에서 열고 메뉴 확장 프로그램 → Apps Script로 들어가 같은 코드를 붙여넣으면 새 파일을 만들지 않고 그 시트에 기록됩니다.

// 통화노트 연결 코드 — 이 코드는 한 번만 붙여넣으면 됩니다.
// 실제 동작 코드는 아래 주소에서 자동으로 최신 버전을 받아오므로,
// 이후 통화노트가 업데이트돼도 이 스크립트를 다시 고칠 필요가 없습니다.
const LOGIC_URL = "https://land3lab.github.io/mrhomesga/callnote/gs-logic.js";

function doGet(e) { return runCallnote_("handleGet", e); }
function doPost(e) { return runCallnote_("handlePost", e); }

function runCallnote_(fnName, e) {
  const cache = CacheService.getScriptCache();
  let code = cache.get("callnote_logic");
  if (!code) {
    code = UrlFetchApp.fetch(LOGIC_URL, { muteHttpExceptions: true }).getContentText();
    if (code && code.indexOf("__logic__") > -1) {
      try { cache.put("callnote_logic", code, 300); } catch (err) {} // 5분 캐시
    }
  }
  const logic = eval(code + "\n;__logic__;");
  return logic[fnName](e);
}

시트의 1행(제목)과 id 열은 앱이 기록을 찾아 갱신하는 기준이므로 지우지 마세요. 이 연결 코드는 한 번만 붙여넣으면 됩니다 — 실제 동작 코드를 자동으로 받아오는 구조라, 이후 통화노트가 업데이트돼도 스크립트를 다시 고치거나 재배포할 필요가 없습니다. (붙여넣거나 교체한 그 때만 배포 → 배포 관리 → ✏️ → "새 버전"으로 재배포)

👥 공유 대상 (직원 주소록)

동료의 웹 앱 URL(동료가 자기 ⚙️ 설정에서 만든 것)을 등록해 두면, 목록에서 매물을 골라 [📤 공유]로 바로 보내줄 수 있습니다. 같은 그룹 이름을 붙이면 그룹 단위로 한 번에 선택돼요 (예: "관악센터").

📖 사용 가이드

갤럭시 (권장) — 통화녹음 파일 공유
  1. 전화 앱 → 우상단 ⋮ → 설정 → 통화 녹음 → 자동 녹음 켜기 (모든 통화 자동 저장)
  2. 통화가 끝나면: 전화 앱 최근기록에서 녹음 재생 화면 → 공유 → 통화노트 선택 (또는 내 파일 → 내장 메모리 → Recordings → Call)
  3. 앱이 자동으로 열리면 [🤖 AI 자동 정리] → 전사 + 상담 카드가 자동으로 채워짐 → 확인 후 저장

※ 공유 목록에 "통화노트"가 보이려면 이 앱을 홈 화면에 설치해야 합니다 (Chrome 주소창 ⋮ → "앱 설치").

스피커폰 통화 중 실시간 받아쓰기
  1. 전화가 오면 스피커폰으로 전환
  2. 통화노트를 열고 [🎙️ 받아쓰기 시작] → 대화가 실시간으로 텍스트로 쌓임
  3. 통화 종료 후 [🤖 AI 자동 정리]

※ 기기 마이크 성능에 따라 상대방 음성 인식률이 낮을 수 있습니다. 중요한 통화는 녹음 파일 방식을 권장. (안드로이드 Chrome에서 가장 잘 동작)

🎙️ 마이크 권한 설정 (받아쓰기가 안 될 때)
  1. 처음 [🎙️ 받아쓰기 시작]을 누르면 브라우저가 마이크 허용을 물어봅니다 → 허용을 누르면 끝.
  2. 실수로 차단했다면 다시 물어보지 않으므로 직접 풀어야 합니다:
    • 안드로이드 Chrome(브라우저로 쓸 때): 주소창 왼쪽 자물쇠(🔒/⚙) 터치 → 권한 → 마이크 → 허용
    • 홈 화면에 설치한 통화노트 앱: 앱 화면 우상단 ⋮ → 앱 정보(또는 ⓘ) → 권한 → 마이크 → 허용. 또는 폰 설정 → 애플리케이션 → 통화노트(없으면 Chrome) → 권한 → 마이크
    • 아이폰 Safari: 주소창 왼쪽 ᴀA → 웹사이트 설정 → 마이크 → 허용. 안 보이면 폰 설정 → Safari(또는 설정 → 앱 → Safari) → 마이크
  3. 폰 자체 마이크가 꺼진 경우: 설정 → 개인정보 보호 → 권한 관리자 → 마이크에서 Chrome이 허용인지 확인.
아이폰
  1. iOS는 앱이 통화를 직접 녹음하는 것을 허용하지 않습니다.
  2. iOS 18 이상: 통화 중 화면 좌상단 녹음 버튼 → 통화 후 메모 앱에 녹음+전사가 저장됨 → 전사 텍스트를 복사해서 통화노트에 붙여넣고 [🤖 AI 자동 정리]
  3. 또는 통화 직후 [🎙️ 받아쓰기]를 켜고 내용을 말로 요약해도 됩니다.
👥 직원들과 함께 쓰기 — 각자 매물장 + 골라서 공유

기본 원칙: 매물장은 각자 개인 것입니다. 각자 자기 폰에 기록하고 자기 시트에 백업하며, 공유하고 싶은 매물만 골라서 보냅니다.

  1. 직원 각자 설치·설정: 앱 설치(웹 land3lab.github.io/mrhomesga/callnote 또는 APK) → 각자 AI 키 발급 → 각자 [📊 내 매물장 시트] 연결 (각자 자기 구글 계정으로)
  2. 서로 주소록 등록: 각자 ⚙️ 설정의 내 웹 앱 URL을 동료에게 알려주고, 서로 [👥 공유 대상]에 이름·그룹과 함께 추가 (예: 그룹 "관악센터")
  3. 보내기: 목록에서 [📤 매물 공유하기] → 매물을 터치해 선택 (1건, 여러 건, [전체 선택] 모두 가능) → [보내기] → 직원 개인 선택 또는 그룹 버튼으로 한 번에 선택 → 전송. 기록 열람 중에는 [📤 공유] 버튼으로 그 매물만 바로 보낼 수 있어요.
  4. 받기: 받는 직원은 아무것도 안 해도 됩니다 — 앱을 열면 자기 시트(수신함)에서 자동으로 받아와 매물장에 추가됩니다. 바로 확인하려면 [🔄 시트에서 받기].

보낸 매물은 받는 사람의 매물장에 복사됩니다 — 이후 각자 수정해도 서로에게 영향을 주지 않습니다. 다시 보내면 최신 내용으로 갱신돼요.
