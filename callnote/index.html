📊 매물장 시트 연결

매물장 파일(시트)은 사무실에 하나 — 사장님이 아래 "시트 연결하는 법"으로 한 번만 연결하면, 시트 파일은 사장님 구글 드라이브에만 생깁니다. 직원은 [🧑‍💼 직원 관리]에서 추가하고, 발급된 초대코드로 접속하면 모두의 기록이 이 한 시트에 모여 서로 공유됩니다.

사장님에게 받은 웹 앱 URL과 초대코드를 입력하면 끝입니다 (스크립트 설정은 필요 없어요). 사무실 매물장이 자동으로 공유됩니다.

🧑‍💼 직원 관리 (사장 전용)

직원을 추가하면 초대코드가 발급됩니다 — [📋 초대문]을 눌러 카톡으로 보내주세요. 직원을 삭제하면 그 즉시 그 직원 앱은 매물장에 접근할 수 없게 됩니다.

🔧 시트 연결하는 법 (사장님이 한 번만, 5분)

⚠️ PC 브라우저에서 하는 것을 권장합니다. 폰의 구글시트 앱에는 스크립트 메뉴가 없어요. (폰밖에 없다면 Chrome 주소창 ⋮ → "데스크톱 사이트" 체크 후 진행 가능)

  1. 브라우저에서 script.google.com/create 접속 (구글 로그인) — 시트를 미리 만들 필요 없습니다, 나중에 자동 생성돼요
  2. 편집기 가운데 있는 기존 코드(function myFunction()…)를 모두 지우고, 아래 [📋 코드 복사]를 눌러 붙여넣기
  3. 위쪽 💾(프로젝트 저장) 클릭 — 프로젝트 이름은 아무거나 (예: 매통이)
  4. 우상단 파란 배포 → 새 배포 → 왼쪽 ⚙️(유형 선택) → 웹 앱 → "액세스 권한이 있는 사용자"를 모든 사용자로 바꾸고 → 배포
  5. "액세스 승인" 버튼 → 내 구글 계정 선택 → "확인되지 않은 앱" 경고가 나오면 고급 → (프로젝트명)(으)로 이동 → 허용 (방금 본인이 만든 코드라 안전합니다)
  6. 생성된 웹 앱 URL(https://script.google.com/…/exec) 복사 → 위 칸에 붙여넣고 [저장] — 저장하는 순간 기존 기록까지 전부 자동 전송되고, 구글 드라이브에 "매통이 매물 접수장" 시트가 자동으로 생깁니다
  7. [🔍 연결 테스트]를 눌러 확인 — "✅ 연결 성공"과 함께 시트를 여는 링크가 나오면 완료. 실패 메시지가 나오면 그 안내대로 고치면 됩니다

이후에는 아무것도 누를 필요 없습니다 — 기록을 저장·수정·삭제할 때마다 자동 반영되고, 인터넷이 끊긴 상태에서 저장한 기록도 다음에 앱을 열거나 인터넷이 연결되면 자동으로 올라갑니다. [📤 전체 다시 보내기]는 시트를 실수로 지웠을 때 복구용입니다.

※ 이미 쓰던 스프레드시트에 붙이고 싶다면: 그 시트를 PC에서 열고 메뉴 확장 프로그램 → Apps Script로 들어가 같은 코드를 붙여넣으면 새 파일을 만들지 않고 그 시트에 기록됩니다.

// 매통이 연결 코드 — 이 코드는 한 번만 붙여넣으면 됩니다.
// 실제 동작 코드는 아래 주소에서 자동으로 최신 버전을 받아오므로,
// 이후 매통이가 업데이트돼도 이 스크립트를 다시 고칠 필요가 없습니다.
const LOGIC_URL = "https://land3lab.github.io/mrhomesga/callnote/gs-logic.js";

function doGet(e) { return runCallnote_("handleGet", e); }
function doPost(e) { return runCallnote_("handlePost", e); }

function runCallnote_(fnName, e) {
  const cache = CacheService.getScriptCache();
  let code = cache.get("callnote_logic");
  if (!code) {
    code = UrlFetchApp.fetch(LOGIC_URL, { muteHttpExceptions: true }).getContentText();
    if (code && code.indexOf("__logic__") > -1) {
      try { cache.put("callnote_logic", code, 300); } catch (err) {} // 5분 캐시
    }
  }
  const logic = eval(code + "\n;__logic__;");
  return logic[fnName](e);
}

// ⚠️ 지우지 마세요 — 구글이 필요한 권한(시트·속성·잠금·외부연결)을
// 승인 창에 표시하도록 알려주는 선언부입니다 (실제로 실행되지는 않음)
function __scopes__() {
  SpreadsheetApp.getActive();
  PropertiesService.getScriptProperties();
  LockService.getScriptLock();
  UrlFetchApp.fetch("https://example.com");
}

시트의 1행(제목)과 id 열은 앱이 기록을 찾아 갱신하는 기준이므로 지우지 마세요. 이 연결 코드는 한 번만 붙여넣으면 됩니다 — 실제 동작 코드를 자동으로 받아오는 구조라, 이후 매통이가 업데이트돼도 스크립트를 다시 고치거나 재배포할 필요가 없습니다. (붙여넣거나 교체한 그 때만 배포 → 배포 관리 → ✏️ → "새 버전"으로 재배포)

📖 사용 가이드

🧭 사장님 처음 설정 체크리스트 (약 15분, 순서대로)
  1. ☐ 앱 설치 — 폰 Chrome에서 이 페이지 접속 → ⋮ → "앱 설치" (또는 설치파일: github.com/land3lab/mrhomesga/releases 에서 callnote.apk)
  2. ☐ AI 키 등록 — 아래 [🔑 AI 키 발급] 안내대로 발급 → ⚙️ 설정에 붙여넣고 저장
  3. ☐ 매물장 시트 연결 — PC에서 [🔧 시트 연결하는 법]대로 (5분) → [저장] → [🔍 연결 테스트]에 ✅가 떠야 완료
  4. ☐ 통화 자동 녹음 켜기 — 전화 앱 → ⋮ → 설정 → 통화 녹음 → 자동 녹음
  5. ☐ 배터리 설정 — 폰 설정 → 배터리 → 매통이 → "제한 없음" (안 하면 폰이 앱을 재워서 통화 감지를 놓칠 수 있음)
  6. ☐ 직원 초대 — [🧑‍💼 직원 관리]에서 이름 넣고 추가 → 복사된 초대문을 카톡 전송
  7. ☐ 시험 통화 — 아무에게나 짧게 통화 → 끊고 몇 초 뒤 알림 → [🤖 지금 AI로 정리] → [💾 저장] → 구글시트에 한 줄 생겼는지 확인. 여기까지 되면 끝!
🧭 직원 처음 설정 체크리스트 (약 5분)
  1. ☐ 사장님이 보낸 초대문의 주소로 앱 설치 (Chrome ⋮ → 앱 설치, 또는 callnote.apk)
  2. ☐ 처음 열리는 화면(마법사)에서 [직원 (초대받음)] 선택 → 초대문의 URL과 초대코드 입력 → 완료 (놓쳤다면 ⚙️ 설정 → 역할 [직원]에서 입력)
  3. ☐ AI 키 등록 — 아래 [🔑 AI 키 발급]대로 본인 키 발급 → ⚙️ 설정에 저장
  4. ☐ 통화 자동 녹음 켜기 + 배터리 "제한 없음"
  5. ☐ ⚙️ 설정 → [🔍 연결 테스트]에 "직원으로 연결" ✅ 확인 — 이제 사무실 매물장이 자동으로 공유됩니다
🔑 AI 키 발급 — 화면 그대로 따라하기

매통이의 받아쓰기·자동 정리는 구글의 AI(Gemini)를 사용합니다. 열쇠(API 키)를 한 번만 발급받으면 되고, 무료입니다.

  1. 브라우저에서 aistudio.google.com/apikey 접속
  2. 구글 계정으로 로그인 (지메일 계정 — 없으면 가입 먼저)
  3. 처음이면 약관 동의 화면이 나옵니다 → 체크 → 계속
  4. 파란 [+ API 키 만들기](Create API key) 버튼 클릭 → 잠깐 기다리면 AIza…로 시작하는 긴 글자가 만들어집니다 — 이게 키입니다
  5. 키 옆 복사(📋) 아이콘 → 매통이 ⚙️ 설정 → Gemini API 키 칸에 붙여넣기 → [저장]
  • 요금: 무료 등급으로 하루 수십 통 정리에 충분합니다. 결제 카드를 등록하지 않으면 요금이 나갈 방법 자체가 없습니다.
  • 보안: 키는 비밀번호처럼 취급하세요. 직원들도 각자 발급하는 것을 권장합니다 (한 키를 나눠 쓰면 무료 한도를 같이 소모).
  • "API key not valid" 오류가 나면: 붙여넣을 때 앞뒤에 공백/줄바꿈이 들어갔는지 확인하고 다시 복사해 보세요.

🎙️ 마이크 권한 설정 (받아쓰기가 안 될 때)

  2. 실수로 차단했다면 다시 물어보지 않으므로 직접 풀어야 합니다:
    • 안드로이드 Chrome(브라우저로 쓸 때): 주소창 왼쪽 자물쇠(🔒/⚙) 터치 → 권한 → 마이크 → 허용
    • 홈 화면에 설치한 매통이 앱: 앱 화면 우상단 ⋮ → 앱 정보(또는 ⓘ) → 권한 → 마이크 → 허용. 또는 폰 설정 → 애플리케이션 → 매통이(없으면 Chrome) → 권한 → 마이크
    • 아이폰 Safari: 주소창 왼쪽 ᴀA → 웹사이트 설정 → 마이크 → 허용. 안 보이면 폰 설정 → Safari(또는 설정 → 앱 → Safari) → 마이크
  3. 폰 자체 마이크가 꺼진 경우: 설정 → 개인정보 보호 → 권한 관리자 → 마이크에서 Chrome이 허용인지 확인.

👥 사무실에서 함께 쓰기 — 하나의 매물장, 직원은 사장님이 관리

매물장 파일(시트)은 사무실에 하나, 사장님 구글 드라이브에만 있습니다. 직원은 초대코드로 접속해 함께 쓰고, 사장님이 직원을 추가·삭제합니다.

  1. 사장(한 번만): [📊 매물장 시트 연결]에서 역할 사장 → [🔧 시트 연결하는 법]대로 연결 → [저장]
  2. 사장: [🧑‍💼 직원 관리]에서 직원 이름 입력 → ＋ 직원 추가 → 자동 복사된 초대문을 카톡으로 직원에게 전송
  3. 직원: 앱 설치 → ⚙️ 설정 → 역할 직원 → 받은 URL·초대코드 입력 → [저장]. 끝 — 스크립트 설정이 필요 없습니다
  4. 이후 누가 저장하든 모두의 앱과 시트에 자동 공유됩니다 (앱을 열 때 자동 수신, [🔄 시트에서 받기]로 즉시 확인)
  5. 직원 삭제: [🧑‍💼 직원 관리]에서 삭제 → 그 즉시 접근 차단. 시트 파일과 [⬇️ 내보내기]는 사장만 사용할 수 있습니다

※ 직원 앱 화면에도 매물이 보이는 것은 업무상 어쩔 수 없으므로, "완전한 유출 방지"보다는 퇴사 후 접근 차단 + 파일 관리 권한 분리 개념입니다. [👥 공유 대상(주소록)]은 다른 사무실 등 외부와 매물을 주고받을 때 쓰는 별도 기능입니다.

관리자 키는 사장 폰에만 저장되므로, 폰을 바꾸거나 앱 데이터를 지우면 [직원 관리]가 동작하지 않습니다. 복구는 스크립트를 만든 구글 계정의 주인만 할 수 있습니다 (이것이 곧 소유권 증명):

  1. PC 브라우저에서 script.google.com 접속 → 사장님 구글 계정으로 로그인 → 내 프로젝트(매통이) 열기
  2. 왼쪽 ⚙️ 프로젝트 설정 → 아래 스크립트 속성에서 adminKey 행을 삭제 후 저장
  3. 새 폰의 매통이 ⚙️ 설정 → 역할 [사장] → URL 입력 → [저장] → 새 폰이 관리자로 등록됩니다 (직원 명단은 그대로 유지)

매물 기록도 옮기려면: 새 폰에서 [🔄 시트에서 받기]를 누르면 시트에 있는 기록이 전부 들어옵니다.

  • 직원 폰에 매물이 안 보여요 → 직원 폰에서 역할이 [직원]인지, 초대코드가 맞는지 → [🔍 연결 테스트] → [🔄 시트에서 받기]. 사장님이 그 직원을 삭제했다면 다시 추가해서 새 코드를 보내야 합니다.
  • 기록이 사라졌어요 → 브라우저 데이터(캐시/사이트 데이터)를 지우면 폰 안의 기록이 지워집니다. 시트에 올라가 있던 기록은 [🔄 시트에서 받기]로 복구됩니다.
  • 새 기능이 안 보여요 → 앱을 완전히 닫았다가(최근 앱에서 밀어서 제거) 다시 열어보세요.
