# 🎫 매통이 라이선스 서버 — 판매자(RSAR) 전용 안내

매통이는 **설치 후 30일 무료 체험 → 이후 이용코드 필요** 구조다.
이용코드 발급·관리는 판매자의 구글시트("매통이 라이선스")가 담당하며,
서버·결제시스템 없이 시트가 곧 판매 장부다.

## 1. 라이선스 서버 배포 (한 번만, 5분)

매물장 시트 연결과 똑같은 절차다 (PC 권장):

1. **script.google.com/create** 접속 (RSAR 구글 계정 로그인)
2. 기존 코드를 지우고 아래 연결 코드 붙여넣기 → 💾 저장 (프로젝트 이름: 매통이라이선스)

```javascript
// 매통이 라이선스 서버 연결 코드 — 실제 로직은 아래 주소에서 자동 업데이트됩니다
const LOGIC_URL = "https://land3lab.github.io/mrhomesga/callnote/gs-license.js";

function doGet(e) { return runLic_("handleGet", e); }
function doPost(e) { return runLic_("handlePost", e); }

function runLic_(fnName, e) {
  const cache = CacheService.getScriptCache();
  let code = cache.get("maetong_lic_logic");
  if (!code) {
    code = UrlFetchApp.fetch(LOGIC_URL, { muteHttpExceptions: true }).getContentText();
    if (code && code.indexOf("__logic__") > -1) {
      try { cache.put("maetong_lic_logic", code, 300); } catch (err) {}
    }
  }
  const logic = eval(code + "\n;__logic__;");
  return logic[fnName](e);
}
```

3. **배포 → 새 배포 → 웹 앱** → 액세스 "**모든 사용자**" → 배포 → 권한 승인
4. 생성된 **웹 앱 URL(…/exec)을 개발자(Claude)에게 전달** →
   `callnote/index.html`의 `const LICENSE_URL = ""` 에 고정해서 재배포하면
   전 세계 모든 매통이 앱이 이 서버로 이용권을 확인한다.
   (직접 하려면 GitHub에서 index.html의 해당 줄에 URL을 넣고 커밋하면 됨)

> URL이 고정되기 전까지 앱은 "기기 자체 판정"으로 동작한다:
> 체험 30일 후 `MT-`로 시작하는 코드를 넣으면 1년 인정. (임시 방식 — 서버 연결 후엔
> 시트에 있는 코드만 유효)

## 2. 이용코드 발급 = 시트에 한 줄 추가

배포 URL을 브라우저에서 한 번 열면(연결 테스트) 드라이브에 **"매통이 라이선스"** 시트가 생긴다.

**[코드] 탭**에 행을 추가하면 그 즉시 유효한 코드가 된다:

| 코드 | 만료일 | 메모 | 사용기기수 | 최초사용일 |
|---|---|---|---|---|
| MT-GWANAK-01 | 2027-07-18 | 관악A사무실 (연 12만원) | (자동) | (자동) |
| MT-DEMO | 2026-08-18 | 지인 체험 연장 | (자동) | (자동) |

- **코드**: 원하는 문자열 아무거나 (MT- 접두어 권장, 대소문자 무관)
- **만료일**: `YYYY-MM-DD`. 비우면 무기한. 연장하려면 날짜만 수정 — 앱이 다음 실행 때 자동 반영
- **회수(환불/미납)**: 행을 삭제하거나 만료일을 과거로 → 그 코드를 쓰던 앱은 다음 실행 때 잠김
- 사용기기수·최초사용일은 자동 기록 — 한 코드를 몇 대가 쓰는지 보인다 (사무실당 1코드 판매 시 참고)

**[기기] 탭**에는 앱 설치 기기마다 최초 실행일이 자동 기록된다 — 체험 30일의 서버측 기준이라,
사용자가 앱 데이터를 지워도 (같은 기기ID가 유지되는 한) 체험이 초기화되지 않는다.

## 3. 판매 흐름 예시

1. 고객(다른 사무실 사장)에게 INTRO.md의 소개글 + 설치 주소 전송
2. 고객이 설치 → 30일 무료 체험 (앱 ⚙️ 설정에 "체험 D-xx" 표시)
3. 결제 확인 후 [코드] 탭에 코드 발급 → 고객에게 코드 전송
4. 고객이 앱 ⚙️ 설정 → 🎫 이용권에 코드 입력 (만료 후엔 잠금 화면에서 바로 입력 가능)

## 솔직한 한계

- 공개 웹앱 특성상 마음먹은 개발자는 우회할 수 있다 — 일반 사용자 기준의 잠금이다.
- 만료돼도 기존 기록 조회·백업은 막지 않는다 (데이터 볼모는 평판에 해롭다).
- 기기 초기화 + 앱 재설치 시 새 기기로 인식돼 체험이 다시 시작될 수 있다.
  [기기] 탭에서 비정상 패턴(같은 사무실의 반복 신규 기기)을 눈으로 확인할 수 있다.
