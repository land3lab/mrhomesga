## ① 짧은 소개글 (카톡/문자용)

📞 **매통이 — 전화만 하면 매물장이 저절로 채워집니다**

부동산 사무실의 하루는 전화로 시작해서 전화로 끝나죠.
매통이는 통화가 끝나면 **녹음을 AI가 알아서 받아쓰고**,
이름·연락처·단지·가격·평형·입주일·할 일까지 **매물 카드로 자동 정리**해 주는 앱입니다.

- 통화 끝 → 알림 탭 → 확인·저장. 끝.
- 걸려온 번호는 자동 입력, 정리된 기록은 구글시트 매물장에 자동 백업
- 직원들과 하나의 매물장 공유 (사장님이 초대·삭제 관리)
- 서버·월 이용료 없음, 데이터는 내 폰과 내 구글 계정에만

👉 설치: https://land3lab.github.io/mrhomesga/callnote/
   (갤럭시 앱: https://github.com/land3lab/mrhomesga/releases)

## ② 기능 소개글 (상세 버전)

# 📞 RSAR Land3 매통이
### 통화 한 통이 매물 카드 한 장이 되는 부동산 상담 자동정리 앱

**"방금 전화 주신 분이 몇 동 몇 평이었지?"** — 상담 전화가 몰리는 날, 포스트잇과
수첩에 흩어진 메모 때문에 놓친 매물이 있진 않으셨나요? 매통이는 통화 그 자체를
기록으로 바꿉니다.

## 이렇게 동작합니다

1. **통화 종료를 자동 감지** — 전화를 끊으면 몇 초 뒤 "통화 녹음이 저장됐어요" 알림
2. **알림 탭 → [🤖 지금 AI로 정리]** — AI가 녹음 전체를 받아쓰고 상담 카드로 정리
3. **확인하고 저장** — 자동 완성된 카드에서 틀린 부분만 고치면 끝
4. **구글시트 매물장에 자동 기록** — 저장하는 순간 사무실 매물장에 한 줄 추가

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🎙️ **통화 자동 전사** | 갤럭시 통화 녹음을 AI(Google Gemini)가 한국어로 받아쓰기 — 화자(중개사/고객) 구분 |
| 🗂️ **매물 카드 자동 완성** | 구분(매물접수/손님문의/계약진행) · 이름 · 연락처 · 물건종류 · 거래유형 · 주소/단지 · 매매가/보증금/월세 · 평형 · 층 · 입주일 · 특이사항 · 할 일 · 한 줄 요약 |
| 📱 **발신번호 자동 입력** | 걸려온(건) 번호와 연락처에 저장된 이름을 자동으로 채우고, 통화 중 언급된 다른 번호도 함께 기록 |
| 📊 **구글시트 매물장** | 저장·수정·삭제가 사무실 스프레드시트에 실시간 자동 반영 — 오프라인 저장분도 나중에 자동 전송 |
| 👥 **직원 공유 (사장 관리)** | 매물장은 사무실에 하나, 직원은 초대코드로 접속. 사장님이 앱에서 직원 추가·삭제 — 삭제 즉시 접근 차단, 시트 파일과 내보내기는 사장만 |
| 📤 **매물 골라 보내기** | 다른 사무실과는 매물 1건/여러 건/전체를 골라서 전송 (개인/그룹) |
| 🔍 **검색·필터·바로 전화** | 이름·단지·내용으로 검색, 구분별 필터, 번호 터치로 바로 통화, 카톡용 복사 |
| 🎤 **받아쓰기·붙여넣기** | 스피커폰 통화 중 실시간 받아쓰기, 아이폰 통화요약 텍스트 붙여넣기도 지원 |

## 안심하고 쓰세요

- **서버가 없습니다** — 기록은 내 폰과 내 구글 계정(시트)에만 저장됩니다.
  AI 정리를 누를 때만 해당 통화가 Google AI로 전송됩니다.
- **비용이 없습니다** — 앱 무료, AI는 구글 무료 등급으로 충분, 시트도 무료.
- **퇴사자 관리** — 직원 삭제 버튼 하나로 즉시 접근 차단.

3. 자세한 내용은 앱 안 **⚙️ 설정·가이드**의 체크리스트 참고
